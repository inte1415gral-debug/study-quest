# Study Quest
学習時間をXPとして記録し、レベルに応じてバッジ報酬を獲得するWebアプリです。

## 機能
- 学習内容と時間の登録
- 合計時間、完了数、レベルの計算
- 完了切替・削除
- レベルが上がるごとに必要XPが60ずつ増加（60 XP、120 XP、180 XP…）
- Lv.2〜100の節目で全26種類の称号バッジを解放
- SQLiteでデータを保存

## 起動
```bash
docker compose up --build
```
ブラウザで http://localhost:8000 を開きます。終了は `docker compose down` です。

## 生成AIの利用
企画、Flask実装、Docker設定、UI、レベル報酬機能、README作成に生成AIを利用しました。

## 称号一覧
Lv.2〜30では成長初期の称号を細かく獲得でき、Lv.35以降は5レベルごとに新しい称号を獲得します。最終称号はLv.100「究極の学習神」です。
